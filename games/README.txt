Pasta de jogos do PS2 na Sala
=============================

Coloque aqui as cópias (dumps) dos SEUS discos: .iso, .cso, .chd, .isz, .bin
ou programas .elf. O serve.py publica esta pasta em /games/ e o site mostra
cada arquivo na estante, pronto para jogar, sem escolher
arquivo nem copiar nada para o navegador.

- Discos .iso/.bin são reconhecidos pelo serial (SYSTEM.CNF) e ganham a capa
  do catálogo quando o jogo está nele. Os outros aparecem com o nome do arquivo.
- .cso/.chd/.isz não têm serial legível: aparecem com o nome do arquivo.
- Só arquivos direto nesta pasta (subpastas e arquivos começando com "." são
  ignorados). Depois de adicionar, recarregue a página.
- O jogo é lido aos poucos (pedidos HTTP Range de 1 MB), não carregado inteiro.

Este README não aparece na estante.
